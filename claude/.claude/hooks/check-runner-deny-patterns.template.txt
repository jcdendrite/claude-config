# check-runner-bash-guard.sh project-layer deny patterns — TEMPLATE.
#
# This is the reference template. To use it in a project, copy this
# file to that project's `<repo-root>/.claude/check-runner-deny-patterns.txt`
# (the hook reads from that path at decision time) and uncomment the
# patterns the project's stack actually uses. The hook reads the
# project file from the worktree's cwd; this template file itself is
# not read at runtime.
#
# Each non-blank, non-comment line is a POSIX extended regex (grep -E)
# matched against each shell fragment of the Bash command after
# splitting on `;`, `&&`, `||`, `|`. A match denies the call with a
# HOOK_BLOCK verdict and cites this file's path and the matched line
# number. A malformed regex on a single line logs to stderr and is
# skipped; sibling lines still apply. If this file is unreadable, the
# hook logs and continues with global-only enforcement.
#
# The patterns are scoped to check-runner's checks-only charter — the
# subagent has no guaranteed cwd and must not mutate shared state.
# Add patterns for state-mutating shapes specific to this project's
# stack. The global hook already covers vendor-name-free shapes
# (`<word> db reset|push|migrate|seed`, force-pushes, hard resets,
# `rm -rf` of root/HOME/~).
